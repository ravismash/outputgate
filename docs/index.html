Three answers that looked right

outputgate checks the structured output an LLM returns with deterministic rules: schema, types, arithmetic across fields, and provenance, which means every value carries a quote of the source and must equal the number that quote prints. No check calls a model.

The example dataset is 120 balance sheets from SEC 10-Q filings, with each filing's own XBRL figures as ground truth. The three cases below are real answers from qwen2.5:14b running locally. Pick a case, switch between contract versions, and click any field to find its quote on the page.

  • schema
  • type
  • math
  • provenance
  • region
  • regex

Every answer, verdict and violation on this page is read from the recorded runs: results.jsonl and repair.jsonl under outputgate-eval/datasets. The CTVA verdict under the region rule comes from re-scoring the recorded answer with the current contract, and is marked post-hoc because the rule was written after seeing that case.

Regenerate with python3 -I outputgate-eval/scripts/build_viewer.py. Source and full benchmark: github.com/ravismash/outputgate.
